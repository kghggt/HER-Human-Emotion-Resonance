# 📝 HER v2.0.0 版本说明

发布日期：2026-05-25

HER v2.0.0 迎来了一次全方位的重构与视觉飞跃，在架构健壮性、高分屏视觉表现及人声自然交互上实现了极大的优化。

## 🌟 核心升级

### 🎨 极光暗黑玻璃拟态 UI (Premium Theme)
* **呼吸发光特效**：伴侣头像与发送按钮引入极具科技感的呼吸微光与阴影。
* **物理滑入动画**：消息气泡新增 300ms 物理弹性滑入动画，多维呈现，更灵动。
* **星空暗色背景**：重绘为更深邃的高级星空黑 `#080818` 调色板。
* **磨砂玻璃输入栏**：输入框采用圆角加半透明 rgba 设计。

### 🔊 智能动作描述 TTS 净化 (Action-Filter Technology)
* **神态噪音正则过滤**：自动识别伴侣回复中含有的如 `（害羞地低头）`、`*微笑*` 等动作括号，**在聊天气泡中完整保留展示，但在合成语音时自动完美净化清除**，防止 TTS 机械性念出动作词。

### 🚀 高 DPI 视网膜缩放适配
* 全面适配 `AA_EnableHighDpiScaling` 像素无损缩放，在高分辨率（2K/4K）屏幕下完美渲染，字字细腻清晰。

### 📂 现代模块化架构重塑
* 摒弃了初版单文件臃肿代码，解耦为 `assistant.py` (引导入口)、`chat_window.py` (主窗口)、`widgets.py` (交互组件)、`tts_service.py` (语音进程管理) 和 `ai_client.py` (大模型交互) 5 大核心模块。
