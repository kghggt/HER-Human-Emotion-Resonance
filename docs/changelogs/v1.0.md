# 📝 HER v1.0.0 版本说明

发布日期：2026-05-18

HER 的首个正式版本，确立了 AI 文字聊天伴侣与原生语音合成的核心框架。

## 🌟 核心特性
* **核心聊天系统**：基于 OpenAI 兼容 API 接入大语言模型（如 DeepSeek-V3），支持打字机效果及实时对话。
* **本地化语音合成**：集成本地轻量化 `GPT-SoVITS` 语音模型引擎，通过 `winsound` 实现低延迟的原生音频播放。
* **极简设置窗口**：支持在界面中直接修改 API Key、API 地址、GPT/SoVITS 模型权重路径等核心参数。
* **初版 UI 界面**：基于 PyQt5 实现的基础淡蓝/暗色渐变气泡窗口。
